┌─────────┬────────┬─────────────────────────────────────────────────────────┐
│   ID    │ Crit.  │ Description                                             │
├─────────┼────────┼─────────────────────────────────────────────────────────┤
│ RES-1   │ FAIBLE │ api/index.php L82 : La vérif X-Requested-With peut      │
│         │        │ être contournée en envoyant le header avec une requête  │
│         │        │ cross-origin (CORS). Protection partielle uniquement.  │
├─────────┼────────┼─────────────────────────────────────────────────────────┤
│ RES-2   │ FAIBLE │ login.php L34 : usleep() bloque le processus PHP.      │
│         │        │ En cas de forte charge, cela peut ralentir le serveur. │
│         │        │ Alternative : sleep() natif ou tokenPoW côté client.   │
├─────────┼────────┼─────────────────────────────────────────────────────────┤
│ RES-3   │ FAIBLE │ assets/js/caisse.js L159 : Pas de vérification CORS    │
│         │        │ avant l'appel fetch() à l'API. Les navigateurs modernes │
│         │        │ bloquent les requêtes cross-origin par défaut, mais    │
│         │        │ la protection est passive.                             │
└─────────┴────────┴─────────────────────────────────────────────────────────┘
