4.1  config/connexion.php (469 lignes) — QUALITÉ : EXCELLENTE
----------------------------------------------------------------------

✅ Corrections vérifiées :
  - SEC-1+2 : Fallbacks supprimés, .env obligatoire
  - BUG-6  : paginate() améliorée avec param optionnel
  - Chargeur .env fonctionnel

⚠️  NOU-6 : La regex de paginate() peut corrompre les SQL contenant
    des alias AS avant FROM :
    Exemple : "SELECT a.*, b.nom AS alias FROM articles a..."
    → La regex capture "a.*, b.nom AS alias" au lieu de juste "a.*"

    Suggestion : Utiliser une regex plus cible :
    $countSql = preg_replace('/SELECT\s+(?!.*\bFROM\b).*?(?=\s+FROM\s)/is',
                             'SELECT COUNT(*) FROM ', $sql, 1);

4.16 login.php (161 lignes) — QUALITÉ : BONNE
----------------------------------------------------------------------

⚠️  NOU-3 : Pas de protection anti-timing :
    Si l'utilisateur n'existe pas, la fonction retourne immédiatement.
    → Une attaquant peut mesurer le temps de réponse pour deviner
      si un login existe ou non.

    Correction : Ajouter un délai artificiel quand l'utilisateur
    n'existe pas :
    if (!$u) {
        usleep(random_int(100000, 300000)); // 100-300ms
    }
